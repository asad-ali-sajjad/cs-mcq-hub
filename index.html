Common questions

Do I need an account?

No. You can use the workspace immediately without signing up.

Where is my progress saved?

In your browser's local storage. It doesn't sync automatically across devices, so export a JSON backup before clearing browser data or switching browsers.

Does it work offline?

Yes. Over HTTPS or localhost, ReviseLoop caches the app shell and any question bank you visit online so you can keep revising offline. It also runs directly from local files.

Can I use my own questions?

Yes. The quiz workspace accepts custom JSON or JavaScript question banks. Only load JavaScript files from sources you trust.

How the loop works

  • Practise: answer questions in sequential quiz or timed mock exam mode.
  • Review: study explanations and revisit your missed and saved questions.
  • Retry: drill missed questions until you answer them correctly.

About ReviseLoop

ReviseLoop began as an interactive MCQ practice website and grew into a zero-backend exam revision workspace.

It is built with vanilla HTML, CSS, and JavaScript, with a focus on fast Computer Science exam preparation.

Privacy & data

ReviseLoop requires no account and runs without a backend server. All quiz answers, bookmarks, and stats stay in your browser's local storage.

When online, this landing page loads the Fraunces display font from Google Fonts, which sends a standard font request to Google. Static hosting providers and external GitHub links follow their own privacy policies.

Quiz shortcuts

Available inside the quiz workspace:

  • N J ↓ Next question
  • K ↑ Previous question
  • A–D or 1–4 Select an option
  • S Save or unsave question
  • E Reveal answer in Sequential Quiz
  • T Scroll back to top
  • / Focus question search
  • [ Toggle desktop sidebar
  • ? Open shortcuts, Esc Close
