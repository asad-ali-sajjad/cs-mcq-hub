## ✨ Key Features

- **⚡ Zero-Dependency & Lightweight** — Built with pure HTML, CSS, and Vanilla JavaScript for instant loading.
- **🌓 Persistent Dark & Light Mode** — Seamless theme switching synced across pages via `localStorage`.
- **🔍 Real-Time Subject Search** — Instantly filter through Computer Science modules from the home dashboard.
- **📱 Fully Responsive** — Designed to work smoothly on desktop, tablet, and mobile browsers.
- **📶 Offline-Friendly Architecture** — Self-contained static pages that run locally or via GitHub Pages.
